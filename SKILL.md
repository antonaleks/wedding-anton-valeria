# Russian Seasons Invitation — Design System

Этот скилл — единый источник правды для одностраничного сайта-приглашения на свадьбу. Концепция: **heritage minimal с поэтикой Русских сезонов**. Не дворец, не золото, не флористика — а тихий музейный документ, где культурный код считывается через типографику, паузы и одну рукописную линию.

**ВАЖНО:** перед любой правкой сверяйся с разделами «Запреты» и «Дизайн-токены». Если редактируешь motion — раздел «Motion». Если копирайт — «Tone of voice».

---

## 1. Концепция в одной фразе

> Сайт читается как страница из музейного каталога, а не как открытка. Имперскость даётся не декором, а тишиной, типографикой и архивностью.

Финальное направление — **гибрид Heritage Minimal (70%) и Поэтических Русских сезонов (30%)**: архитектура и тишина от первого, точечная поэтика (рукописные обводки, эпиграф, brass-акцент) от второго.

## 2. Дизайн-токены (CSS-переменные)

Используй эти переменные. Не вводи новых цветов без необходимости.

```css
:root {
  /* основа */
  --ivory:    #F2EDE4;  /* главный фон */
  --paper:    #ECE5D8;  /* чуть темнее, для рамок фото */
  --espresso: #211913;  /* основной текст */
  --ink:      #2A2018;  /* альтернативный текст */

  /* акценты */
  --olive:    #6E725C;  /* редко, для разделителей */
  --sage:     #8C8E75;  /* ещё реже */
  --brass:    #A9874D;  /* ЕДИНСТВЕННЫЙ акцент — только в линиях, italic, подписях */
  --warm-gray:#8C8478;  /* caps-метки, подписи */

  /* типографика */
  --display: 'Cormorant Garamond', 'Times New Roman', serif;
  --ui: 'Inter', -apple-system, system-ui, sans-serif;

  --col-w: min(1180px, 92vw);
}
```

**Правила использования цвета:**
- `--brass` — **только** в линиях, italic-словах, подчёркиваниях, hover. Никогда в заливках больше 1px толщины.
- `--olive` / `--sage` — только в редких разделителях. Не используй для текста.
- Основной текст — `--espresso` или `--ink`. Подписи и метаданные — `--warm-gray`.

## 3. Типографика

**Прототип:** Cormorant Garamond (display) + Inter (UI), через Google Fonts.
**Продакшен (после согласования):** Kazimir Display + Kazimir Text (CSTM Fonts, лицензия type.today) + Söhne / ABC Diatype для UI.

**Иерархия размеров:**
- Hero name: `clamp(54px, 11vw, 168px)`, weight 300, line-height 0.92, letter-spacing -0.02em
- Section heading: `clamp(48px, 7vw, 92px)`, weight 300, italic-акценты в brass
- Subheading: `clamp(36px, 5vw, 64px)`
- Body: 18-20px, line-height 1.5-1.6
- Caps-метки (UI): 10-11px, letter-spacing 0.22-0.30em, uppercase, weight 400

**Правила:**
- Один display-шрифт на весь сайт. Никаких script / handwriting шрифтов.
- Italic — для акцентов в заголовках, всегда в `--brass`.
- All-caps + широкий трекинг — только для служебных меток (номера секций, RSVP-метки, даты в footer).
- Числа в заголовках — **прописью** («двенадцатого июля две тысячи двадцать шестого»), не цифрами.
- Даты в служебных подписях — римскими цифрами (`XII · VII · MMXXVI`).

## 5. Структура сайта

**Финальная версия (6 блоков, согласована):**

1. **Hero** — имена «Антон & Валерия», амперсанд italic brass, тонкая линия 64px, три блока метаданных (дата прописью / место / время прописью). Под hero — большое совместное фото пары на всю ширину + caps-подпись.
2. **Вечер (Когда и Где).** Две колонки через тонкий вертикальный divider: «День и час» (одиннадцатого сентября, к трём часам пополудни, гости с 14:30) и «Место» (особняк Путилова, Крестовский остров). Section-num `№ 01 · Вечер`.
3. **Она.** Детское фото Валерии слева, текст справа. Pencil-overlay SVG с обводкой силуэта + букета. Section-num `№ 02 · Она`. Подпись в caps.
4. **Он.** Зеркальная композиция (фото Антона справа). Pencil-overlay: силуэт + карнавальная шапка с иглами + бабочка + листья жилета. Section-num `№ 03 · Он`.
5. **Дресс-код.** Заголовок, лид-абзац, 5 swatches с подписями, итоговая sноска italic warm-gray, ссылка на Pinterest-доску образов. Section-num `№ 04 · Платье`.
6. **Подарки.** Две колонки: конверт + цветочная подписка для Валерии (вместо живых цветов на день свадьбы). Иконки pencil-style. Section-num `№ 05 · Жесты`.

+ минимальный **Footer**: монограмма «А & В» большим brass-italic, дата римскими (XI · IX · MMXXVI), тонкая верт. линия, подпись места.

Эпиграф и RSVP **исключены** по решению пары. Если в будущем понадобится RSVP — добавлять отдельным блоком перед футером, не ломая нумерацию.

**Полная версия (11 секций, для других проектов / референса):**

Порядок и нумерация обязательны. Если добавляешь новую секцию — обсуди со мной, не добавляй молча.

1. **Topbar (sticky).** Тонкая, появляется после первого экрана. Три элемента: монограмма «А · А» / «Приглашение» / RSVP-якорь.
2. **Hero.** Имена крупным серифом в две строки + амперсанд italic brass между ними. Тонкая вертикальная линия 64px. Три блока метаданных (дата / место / время). Стрелка-указатель с медленной float-анимацией.
3. **Эпиграф.** Один экран — одна фраза из Серебряного века (или личная), italic, по центру, под ней caps-cite.
4. **Дом (Мansion).** Архивный снимок особняка в полную ширину. Под ним — две колонки: «Место» (название и год) и «Адрес». Section-num `№ 01 · Дом`.
5. **Она.** Детское фото слева, текст справа. SVG-обводка с дорисовкой пуанты. Section-num `№ 02 · Она`. Подпись фото в caps: «Имя · ~год · место».
6. **Он.** Зеркальная композиция (фото справа). Обводка дорисовывает занавес. Section-num `№ 03 · Он`.
7. **Когда и Где.** Две колонки через тонкий вертикальный divider 240px. Section-num `№ 04 · Вечер`. Время прописью + расписание в caps mono-стиле.
8. **Дресс-код.** Заголовок, лид-абзац, 5 swatches с подписями, итоговая sноска italic warm-gray. Section-num `№ 05 · Платье`.
9. **Подарки.** Две колонки: цветочная подписка + конверт. Каждый блок — рисованная одной линией иконка (букет / конверт с восковой печатью), caps-метка, italic-заголовок, короткий абзац. Section-num `№ 06 · Жесты`.
10. **RSVP.** Компактная форма: имя, статус (3 опции в select), диета, заметка. Кнопка-текст с подчёркивающей линией. Deadline в caps brass над формой. Section-num `№ 07 · Ответ`.
11. **Footer.** Монограмма «A & A» большим brass-italic, дата римскими цифрами в caps, тонкая вертикальная линия 60px, подпись места.

## 6. Motion-правила

**Базовый easing:** `cubic-bezier(.22, 1, .36, 1)` (мягкий out). Никаких bounce, никаких пружин.

**Базовая длительность:** 600–1100мс. Reveal-блоки — 900мс. Обводки SVG — 1400–2200мс с задержками.

**Три «фирменные» motion-фишки:**

### 6.1. Reveal-блоки
```css
.reveal {
  opacity: 0;
  transform: translateY(14px);
  transition: opacity 900ms cubic-bezier(.22,1,.36,1),
              transform 900ms cubic-bezier(.22,1,.36,1);
  transition-delay: var(--d, 0ms);
}
.reveal.in { opacity: 1; transform: none; }
```
Триггер через IntersectionObserver, threshold 0.18, `rootMargin: '0px 0px -8% 0px'`.

### 6.2. Line-reveal заголовков
```css
.lineReveal { display: block; overflow: hidden; }
.lineReveal > span {
  display: inline-block;
  transform: translateY(110%);
  transition: transform 1100ms cubic-bezier(.22,1,.36,1);
  transition-delay: var(--d, 0ms);
}
.lineReveal.in > span { transform: translateY(0); }
```
Используется в hero и заголовках больших секций.

### 6.3. SVG-обводка цветным карандашом (ключевая фишка)

**Главная визуальная фишка проекта.** Каждое детское фото имеет overlay-SVG, в котором силуэт ребёнка и характерный атрибут обведены «цветным карандашом» — несколькими path'ами разных цветов из палитры (brass, olive, dark-bordeaux), пропущенными через SVG-фильтр turbulence + displacement для эффекта неровной карандашной линии.

```svg
<filter id="pencilFilter" x="-10%" y="-10%" width="120%" height="120%">
  <feTurbulence type="fractalNoise" baseFrequency="0.04" numOctaves="2" seed="3" result="t1"/>
  <feDisplacementMap in="SourceGraphic" in2="t1" scale="2.4"/>
</filter>
```

Параметры: `baseFrequency` 0.04–0.06, `scale` 2.4–3 (выше — больше «дрожь»). Два разных фильтра (разные seed) для двух фото — иначе линии слишком похожие.

**Цвета обводки** (CSS-переменные `--pencil-1/2/3`):
- `--pencil-1: #A9874D` (brass) — основная обводка силуэта
- `--pencil-2: #6E725C` (olive) — детали / акценты
- `--pencil-3: #3F1A19` (бордо) — характерный атрибут (букет / шапка)

**Порядок дорисовки:**
- сначала основной силуэт (2000ms, delay 200ms)
- через 1500ms — акценты-олива (1300ms)
- через 2400ms — характерный атрибут другим цветом (1400ms)
- финальные детали (900–1100ms)

```js
document.querySelectorAll('.drawPath').forEach(p => {
  const len = Math.ceil(p.getTotalLength()) + 4;
  p.style.setProperty('--len', len);
  p.style.setProperty('--dur', `${p.dataset.dur || 1400}ms`);
  p.style.setProperty('--d', `${p.dataset.delay || 0}ms`);
});
```

```css
.drawPath {
  stroke-dasharray: var(--len, 1000);
  stroke-dashoffset: var(--len, 1000);
  transition: stroke-dashoffset var(--dur, 1400ms) cubic-bezier(.22,1,.36,1);
  transition-delay: var(--d, 0ms);
}
.drawPath.in { stroke-dashoffset: 0; }
```

**Атрибуты-дорисовки по фото (актуальные):**
- Валерия (она, фото с букетом) → силуэт + куртка + букет в руках (цветной карандаш бордо)
- Антон (он, карнавал) → силуэт + карнавальная шапка с торчащими иглами + бабочка + листья жилета

**Параметры обводки:**
- `stroke: var(--pencil-1|2|3)`
- `stroke-width: 1.1–1.7` (тоньше для акцентов, толще для основного силуэта)
- `stroke-linecap: round`, `stroke-linejoin: round`
- `fill: none`
- группа path'ов оборачивается в `<g filter="url(#pencilFilter)">`

### 6.4. Запрещённые motion-приёмы
- Bounce, elastic, spring easings
- Параллакс больше 10% смещения
- Кастомный курсор
- Hover-эффекты с увеличением (scale > 1.02)
- Карусели, слайдеры
- Любые анимации, проигрывающиеся в loop (кроме медленного float-указателя в hero)

## 8. Tone of voice

**Базовые правила:**
- На «вы», с уважительной дистанцией. Не «приходите праздновать с нами».
- Без восклицательных знаков. Вообще. Эпиграф — единственное исключение, и там лучше точка.
- Без эмодзи.
- Без слов-маркеров шаблонного wedding-стиля: «незабываемый», «волшебный», «любимые», «сладкий», «милый».
- Числа в заголовках — прописью.
- Имена — полные, без уменьшительных.
- Короткие фразы, ритм пауз.

**Примеры (✅ да / ❌ нет):**

| ❌ Шаблонно | ✅ В стиле |
|------------|-----------|
| «Мы счастливы пригласить вас на нашу свадьбу!» | «Приглашаем разделить с нами этот вечер.» |
| «Дресс-код: коктейль» | «Не форма, а настроение.» |
| «Подарки приветствуются» | «Самым тёплым подарком будет ваше присутствие.» |
| «Жду вас, не опаздывайте!» | «Просим ответить до 1 июня.» |
| «Любимая бабушка Зина» | «Та, что умела танцевать раньше, чем ходить.» |

## 9. Запреты (жёсткий список)

**Никогда не делай этого** в этом проекте, даже если пользователь прямо просит. Если просит — переспроси, но предложи альтернативу.

- Декоративные **рамки**, виньетки, орнаменты, флористические паттерны
- **«Золото»** в заливках (только brass-линии)
- **Двуглавые орлы**, короны, гербы, кокошники, матрёшки — любая буквальная «русскость»
- **Дворцовые интерьеры**: канделябры, шторы-золото, балюстрады в декоре (балюстрада в архивном снимке фасада — ок)
- **Скриптовые** «свадебные» шрифты (Allura, Great Vibes, всё подобное)
- **Иконки** в стиле «обручальные кольца / сердечки / голубки»
- **Карточки** с тенями и закруглениями
- **Кнопки-«пилюли»** (capsule). Кнопки — это подчёркнутый текст
- **Карусели**, слайдеры, multi-step формы
- Раздел **«История нашей любви»** с timeline / пошаговой love-story
- **Countdown-таймер** «До свадьбы осталось…»
- **Музыка** на фоне сайта (любая, даже Бородин)
- **Параллакс** агрессивнее 10%
- **Hover-увеличения** фото, scale > 1.02
- **Lightbox** для фото
- **Скролл-снапы** между секциями
- **Стоковые фото** интерьеров / цветов
- **Восклицательные знаки**, эмодзи, слова «волшебный/незабываемый/любимый»
- **Цифры** в крупных заголовках (только прописью)

## 11. Рабочий процесс

При работе над сайтом:

1. **Перед любой правкой** — перечитай разделы «Запреты» и «Дизайн-токены».
2. **При добавлении новой секции** — сверь со списком из раздела 5. Если её там нет — обсуди с пользователем.
3. **При замене фото** — реальные `<img>` идут внутрь `.photo` div'а с `object-fit: cover`. Overlay-SVG с обводкой остаётся как был, нужно только подстроить координаты path под силуэт нового фото (это полу-получасовая работа, делай в отдельном проходе).
4. **При работе с motion** — не вводи новых easing'ов. Используй только `cubic-bezier(.22, 1, .36, 1)`.
5. **При работе с копирайтом** — сверь с разделом 8 и таблицей примеров.
6. **После любой большой правки** — открой результат в браузере, проверь на 380px (мобильный) и 1440px (десктоп).
