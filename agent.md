# Промпт для Claude Code (первое сообщение)

Скопируй и вставь в Claude Code как первое сообщение проекта.

---

Собери одностраничный сайт-приглашение на свадьбу в концепции **«Heritage Minimal × Русские сезоны»** — quiet luxury, editorial, без свадебных клише.

В проекте лежит skill `russian-seasons-invitation` — обязательно прочитай его `SKILL.md` перед тем, как начать работу, и сверяйся с ним на каждом этапе. Там зафиксированы дизайн-токены, шрифтовая пара, палитра, motion-правила, структура секций, tone of voice и список того, чего делать нельзя.

**Стек:** статический HTML + CSS + минимальный vanilla JS (IntersectionObserver для reveal-ов и SVG-обводок). Без фреймворков, без сборщиков. Один `index.html`, при необходимости вынеси CSS и JS в отдельные файлы рядом.

**Что собрать в первом проходе:**
1. Каркас из 11 секций согласно структуре в SKILL.md
2. Шрифтовая пара через Google Fonts: **Cormorant Garamond** (display) + **Inter** (UI) как прототип. Позже заменим на Kazimir.
3. Полная палитра как CSS-переменные.
4. Hero с построчным reveal имён, эпиграф, секция «Дом» с плейсхолдером особняка, две секции детства с SVG-плейсхолдерами и анимированной brass-обводкой через `stroke-dashoffset`, «Когда и Где», dress-code с 5 swatches и подписями к картинам, gifts (цветочная подписка + конверт), компактный RSVP, footer с монограммой.
5. Бумажная текстура через SVG turbulence + film-grain overlay.

**Имена-плейсхолдеры:** Анна и Александр, дата 12 июля 2026, особняк на Поварской. Реальные данные подменю позже.

**Фотографии:** сейчас плейсхолдеры (силуэты в SVG). Реальные пришлю в отдельной итерации — нужно сделать так, чтобы их легко было подменить на `<img>` без переделки обводок.

После того как соберёшь каркас — покажи мне результат и подожди фидбэка перед тем, как продолжать. Не пытайся сделать всё идеально с первого захода: важнее, чтобы я мог итерировать секциями.
